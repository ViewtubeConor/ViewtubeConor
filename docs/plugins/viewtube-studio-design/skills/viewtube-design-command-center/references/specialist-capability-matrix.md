# Specialist capability and boundary matrix

| Skill | Owns | Produces | Must not claim/do |
|---|---|---|---|
| Architecture Steward | Authority, ownership, dependency and root-cause analysis | Source map, conflict register, impact graph | No shadow registry or unapproved production edits |
| Primitive Engine | Inventory, API/capability mapping, composition | Primitive matrix, compatibility map, gap report | No local lookalikes or catalog-as-production claims |
| Visual Reverse Engineering | Reference decomposition | Anatomy, geometry, Studio mapping | No overriding canonical Studio contracts |
| Visual Intelligence Engine | Measured visual analysis and mapping | Segmentation, geometry, visual delta, confidence | No DOM measurement claims from static images |
| Relationship Explorer | Consumer/export/style/token/generator/test graph | Dependency map and impact matrix | No second registry or unverified deletion |
| Token Inspector | Canonical token lineage and use-site drift | Definition-to-generator-to-use-site trace | No parallel token store or generated-file edits |
| Adoption/Migration Planner | Primitive adoption and consumer migration | Compatibility matrix, rollout and rollback plan | No migration based only on visual similarity |
| Contract Enforcement | Contract coverage and owner-layer drift | Pass/fail/unknown matrix | No invented rules or unapproved contract changes |
| Unified Design Audit | Cross-lane audit consolidation | Coverage and deduplicated priorities | No unsupported exhaustive coverage claims |
| UX/Accessibility | Journeys, keyboard/focus, usability | Journey and tested/not-tested matrix | No fabricated research or WCAG certification |
| Interaction-State Matrix | Risk-based state/viewport/input coverage | Prioritized test matrix | No invented tiers/breakpoints or implied test results |
| Regression Intelligence | Defect-to-test workflow | Regression specification and observed results | No claim prevention without passing tests |
| Visual Diff Triage | Capture comparability and visual difference analysis | Difference inventory and owner hypotheses | No pixel-accuracy claims from incomparable captures |
| Browser/Pixel Verification | Runtime and rendered evidence | Viewport/state screenshots and computed observations | No source-only visual certification |
| Design-System Health Review | On-demand system health snapshot | Health matrix and remediation roadmap | No background monitoring or fabricated score |
| Correction Intelligence | Correction recurrence | Correction record and prevention checklist | No implied hidden database or memory |
| Design-to-Code / Studio Steward | Approved implementation lifecycle | Minimal changes, tests, docs, handoff | No bypassing approvals or claiming unavailable permissions |
| Agent Instruction Controls | Plugin-authored instruction inventory and task-scoped toggles | Traceable checklist, effective task settings, locked-rule explanations | No disclosure/modification of hidden host instructions; no bypass of locked/required rules |

## Evidence vocabulary

`source-confirmed`, `runtime-observed`, `visual-observed`, `test-confirmed`, `hypothesis`, `not-verified`.
