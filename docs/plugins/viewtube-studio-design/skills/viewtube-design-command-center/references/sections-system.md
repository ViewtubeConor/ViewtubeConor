## Shared handoff

Carry goal, repository, exact target ref, working-tree state, sources/revisions, contracts, findings/confidence, approvals, dependencies, scope, acceptance criteria, files, tests, visual evidence, risks, and status. Unknown remains unknown.

## Collaboration

Design Intelligence establishes authority; Component Intelligence verifies reuse; Creative Design and UX share constraints; QA defines acceptance evidence early and consolidates duplicate findings; Implementation cannot convert a proposal into an approved contract. Use the minimum specialist set. One repository source of truth, one production primitive system, one canonical token/generator path, and one shared evidence vocabulary.
