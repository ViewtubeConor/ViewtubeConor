## Limitations

This is an instruction-governance workflow implemented in the plugin's skills, not a new graphical settings panel or autonomous policy runtime. Task overrides are maintained in the current task context; no cross-task persistence is claimed. The package does not grant repository, browser, persistence, monitoring, deployment, or Git permissions. No ViewTube application code, branch, commit, or PR is changed by this plugin-package update.
