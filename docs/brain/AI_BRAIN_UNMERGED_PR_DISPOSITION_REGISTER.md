## Review rules

- “Closed unmerged” is not equivalent to “missing”; verify target ancestry, successor PRs and exact current source.
- “Open” is not an endorsement to merge. Compare each head to current target SHA, not the PR's historical base.
- Branch names and PR descriptions are discovery metadata, not proof of behavior.
- Never merge a divergent feature branch wholesale. Prefer the smallest tested forward-port.
- Preserve source-owner authority and avoid new runtimes, context brokers, evidence stores, Gemini gateways or local shadow ledgers.
